Sauvegarde PC + téléphone

Tes données sont enregistrées dans ton repo GitHub, sur la branche data. Il faut une clé GitHub sur chaque appareil, à coller une seule fois. Sans clé, le site marche quand même mais ne garde les modifs que sur cet appareil.

Créer ta clé (2 minutes, une seule fois)
  1. Ouvre github.com/settings/personal-access-tokens/new
  2. Nom : PDM site. Expiration : 1 an.
  3. Repository access : Only select repositories → pdm-thomas-dos-santos uniquement.
  4. Permissions → Repository permissions → Contents : Read and write. Rien d'autre.
  5. Generate token, copie la clé (commence par github_pat_) et colle-la ci-dessous. Fais pareil sur ton téléphone avec la même clé.
